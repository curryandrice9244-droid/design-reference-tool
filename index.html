Design Reference Tool

A personal tool for collecting, rating and organizing visual references for illustration work, such as costume and accessory designs for characters.

Developer: Tatsuya Ishihara
Contact: curry-and-rice@live.jp
Status: In development (not publicly released)
Intended users: The developer only (personal use)

What it does

When designing outfits for illustrations, I save many reference images on Pinterest. Design Reference Tool helps me review those references efficiently and keep track of which ones are useful.

  • Browse my own Pinterest boards. After I connect my Pinterest account, the app loads the boards and Pins I have saved and shows them in an image grid.
  • Search my saved Pins. Find Pins on my own boards by keyword.
  • Rate and organize. Give each reference a 1–5 star rating, mark favorites, hide images I don't need (and restore them later), write comments, and classify references by theme and by clothing part (tops, skirts, shoes, hair accessories, etc.).
  • Better search suggestions. Based only on my own ratings and tags, the app suggests search keywords that I can use the next time I look for references on Pinterest myself.
  • Open the original Pin. Every reference links back to its Pin on Pinterest.

How it uses the Pinterest API

  • Connects to my account with Pinterest’s official OAuth authorization. The app never asks for or stores my Pinterest password.
  • Uses read-only access to my account information, boards and Pins, including my own secret boards (user_accounts:read, boards:read, pins:read, boards:read_secret, pins:read_secret), so that I can browse and search my own saved Pins. It does not create, edit or delete anything on Pinterest.
  • Pin images and details are loaded from the API each time they are displayed and are not saved by the app. Only Pin IDs and board IDs are stored, so that my own ratings and comments can be linked to the right Pin.
  • Pinterest content is not used to train or develop any AI or machine learning model, and is not sent to any external service.
  • The app does not scrape Pinterest or perform any automated actions on Pinterest.

How it runs

Design Reference Tool is a local web application that runs on my own Windows PC. All data stays on that computer; there is no server operated by the developer that stores user data. See the Privacy Policy for details.
