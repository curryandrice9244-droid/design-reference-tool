Privacy Policy

Effective date: November 19, 2026
Developer: Tatsuya Ishihara

This Privacy Policy explains how Design Reference Tool (“the app”) handles information, including information obtained through the Pinterest API. The app is a personal tool that is currently in development and is used only by its developer.

1. Summary

  • The app runs locally on the user’s own Windows PC. All data is stored only on that computer.
  • The developer does not operate any server that collects or stores user data.
  • Pin images, image URLs and source URLs are not saved by the app. Only Pin IDs and board IDs are stored, together with the user’s own ratings and comments.
  • No information is sold or shared with third parties.
  • Pinterest content is not used to train or develop any AI or machine learning model.

2. Information obtained through the Pinterest API

With the user’s permission, given through Pinterest’s official OAuth authorization, the app uses read-only access (user_accounts:read, boards:read, pins:read) to obtain:

  • Basic account information, such as the username, to show which account is connected;
  • The user’s own boards (board ID, name);
  • Pins saved on those boards (Pin ID, image URL, title, description, and the link to the original source website).

The app never asks for or stores the user’s Pinterest password.

How image URLs, Pin IDs and source URLs are handled

InformationHandling
Pin ID, board IDStored locally, only to link the user’s ratings, comments and classifications to the correct Pin and board, and to open the Pin on Pinterest.
Images and image URLsNot saved by the app. They are requested from the Pinterest API each time they are displayed. The web browser may keep a temporary cache as part of its normal operation.
Source URLs (links to the original website)Not saved by the app. They are requested from the Pinterest API when needed and are only used to let the user open the original source.
Titles, descriptions, account informationNot saved by the app. Used only for display at the time they are requested.

3. Information entered by the user

The app stores the following information that the user enters:

  • Star ratings (1–5), favorites, and hidden/restored status;
  • Comments and ratings on specific parts of an image;
  • Classifications and tags, such as theme, clothing part, color, shape, material, pattern and decoration;
  • Project and theme settings, and search keyword history.

This information is used only to organize references and to suggest search keywords to the user. Keyword suggestions are based solely on the user’s own ratings and tags. Any AI processing used for these features runs locally on the user’s PC, and no Pinterest content is sent to external AI services.

4. Access token

The OAuth access token issued by Pinterest is stored in the Windows Credential Manager on the user’s PC. It is used only to communicate with the Pinterest API and is not sent anywhere else.

5. Where data is stored and for how long

  • Location: A local database (SQLite) on the user’s own Windows PC, and the Windows Credential Manager for the access token. No data is stored on servers operated by the developer.
  • Retention: Stored data is kept until the user deletes it. When the user disconnects their Pinterest account, the access token is deleted.

6. Sharing with third parties

The app does not sell, rent or share any information with third parties. Information obtained through the Pinterest API is used only to provide the app’s features to the user. The app contains no advertising or analytics services.

7. How to delete information

  • Ratings and comments: Can be deleted individually or all at once within the app.
  • Pinterest connection: Disconnecting the account in the app deletes the stored access token. Access can also be revoked at any time from the connected apps section of the user’s Pinterest account settings.
  • All data: Deleting the app’s data folder removes all locally stored information.
  • Requests or questions about deletion can also be sent to the contact address below.

8. This website

This website does not use cookies, analytics or tracking. It is hosted on GitHub Pages, and GitHub may collect technical information such as IP addresses in accordance with the GitHub Privacy Statement.

9. Children

The app is not intended for children under the age of 13.
